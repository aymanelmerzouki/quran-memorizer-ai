## 🔒 Sécurité

### ⚠️ Important

**Ne JAMAIS committer**:
- ❌ Fichiers `.env` avec vraie clé API
- ❌ Keystores de signature
- ❌ Tokens d'accès
- ❌ Credentials AWS/cloud

### ✅ Bonnes Pratiques

```bash
# Toujours utiliser .env.example
cp .env.example .env

# Vérifier avant commit
git status | grep -E "(\.env$|\.key|secret)"

# Auditer dépendances
npm audit
pip check
```
